IT setup · How to connect live answers

Connection method: approved department Google Drive documents → Gemini File Search → answers with citations in Harrow Ask. Opening a NotebookLM link does not connect its answers. NotebookLM sources are refreshed separately.

  1. Prepare the Google project and Drive access. In a school-approved Google Cloud project, enable the Google Drive API and create a dedicated service account. Give its email Viewer access to the approved department source folder. The app uses Drive read-only access without domain-wide delegation. Use an IT-managed service-account PEM key for the server configuration below; if school policy prevents service-account keys or external folder sharing, this pilot needs an alternative approved authentication method before use.
  2. Configure the answer service. Enable access to the Gemini API in an approved project, configure an API key, and select a model that supports File Search with generateContent. Confirm quota and school approval for processing these documents. The app requires an explicit model ID; a NotebookLM subscription or link is not a Gemini API credential.
  3. Configure staff sign-in. Create a Google OAuth client of type Web application. Configure the consent screen for the school and add https://harrow-ask.netlify.app to Authorised JavaScript origins, plus each exact approved preview origin used for testing. This app uses the Google Identity Services JavaScript callback; there is no app OAuth redirect endpoint to invent. The existing Netlify team login is separate from school sign-in within Harrow Ask.
  4. Set Netlify server variables and redeploy. Open the Harrow Ask project's environment-variable settings and apply these to the production Functions scope. Configure previews separately if used. Keep keys out of source code, frontend variables and chat messages.

  1. Assign and sync LS CCA. Sign in to Harrow Ask as an allowlisted administrator. Open Department notebooks, edit Lower School CCA, enter the lead's school email and Drive folder link, approve the documents for all authorised staff and save. Run Sync department and wait for Sync complete; check the source count, source versions and last successful sync. Enable the department when ready for staff use. Keep only supported files directly in the folder: no subfolders or shortcuts, up to 40 files and 8 MB per file. Spreadsheet imports include all worksheets, including hidden ones; use a staff-facing copy with confidential sheets removed.
  2. Verify before staff launch. Test school sign-in, a real LS CCA question, its original document citation, an unsupported question, Thai answers and draft-policy wording. Test that a lead can sync their own department but cannot change another department. Change or remove a test source, sync again and check that answers reflect the new set. A failed sync retains the previous successful set; pause or archive a department for an urgent withdrawal.

Ongoing responsibility: department leads update the approved originals and click Sync department. They refresh NotebookLM separately. IT monitors quota and removes unused Gemini File Search stores; this pilot rebuilds the index each sync and does not automatically delete retired stores.

If the warning remains: confirm all variables exist in the correct deployment context, redeploy after changes, inspect Netlify Function logs without exposing secrets, then check folder sharing, model support, quota and whether an approved, enabled department has successfully synced. A configured service alone does not mean documents have been imported.
